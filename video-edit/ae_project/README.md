# IKEAソフトクリーム リール — After Effects 一式（フルテロップ版）

## 中身

| ファイル | 内容 |
|---|---|
| `build_ikea_edit.jsx` | AEで実行すると、コンポジションを丸ごと組み立てるスクリプト |
| `fonts/` | 代わりのフォント（Zen Kaku Gothic Antique Black ／ しっぽり明朝 B1 ExtraBold）。凸版文久見出しの書体が無いときに使用 |
| `matte/person_matte.mp4` | 人物の切り抜きマスク（白＝人物）。「5倍濃縮」を頭の後ろに回すのに使用 |
| `sfx/sfx_mix.wav` | 効果音をタイミングどおりに並べた1本のトラック（控えめな音量） |
| `sfx/*.wav` | 効果音の単体ファイル（whoosh・thump） |
| `preview.mp4` | 仕上がりイメージ（低画質の確認用） |

## 使い方

1. Adobe Fonts で **凸版文久見出しゴシック** と **凸版文久見出し明朝** を有効にする（スクリプトが自動で使います）。
   使えない場合に備えて、`fonts/` の2つの `.ttf` もインストールしておき、AEを再起動する
2. AEで **ファイル → スクリプト → スクリプトファイルを実行…** を選び、`build_ikea_edit.jsx` を開く
   - フォルダの構成は変えずに、このフォルダの中から実行してください
3. ファイル選択の画面で、**編集前の高画質の素材動画**を選ぶ
4. `IKEA_SoftCream_Reel`（1080×1920・30fps）が自動で作られます

## テロップ（単語が積み上がるキネティックタイポ）

### 基本の動き
- 話した**単語が1つずつ、話した瞬間に**現れます。単語の中は、1文字ずつタイプするように出ます（130%→100%）。
- ひとまとまり話し終えるまで単語が画面に残り、顔を避けた空いた場所に**階段状に積み上がって**から、まとめて消えます。
- 顔の横の細い列には、**縦書き**の単語を置いています。
- 書体は、ゴシック（凸版文久見出しゴシック）と明朝（凸版文久見出し明朝）を混ぜています。「の」「は」「って」のようなつなぎの言葉は明朝で小さく、中身の言葉はゴシックで大きくしています。

### 色の使い分け
| 背景 | 普通の単語 | 強調する単語 |
|---|---|---|
| 暗い場面（冒頭の外観・マシン） | 白（細い黒の縁取り） | 黄色の文字 |
| 明るい場面（店内・キオスク・食べるところ） | 黒（うっすら白いぼかし付き） | 黒い文字＋黄色の蛍光ペンの帯 |

見本で赤だったところは、どちらの場面でも黄色にしています。

### 強調の動き
- 金額（50円・150円・112円）は、ポンと出てから、数字がスロットのように回って止まります。
- 「押すだけ」は、ボタンのようにグニッと潰れて戻ります。
- 「5倍濃縮」は、頭の後ろに回り込みます。

### 手描き風の飾り（線が描かれていくアニメーション）
| 時間 | 飾り |
|---|---|
| 1.25秒 | 「いくら？」の横に「!!」風の3本線 |
| 4.3秒 | 「50円」の横に3本線 |
| 8.3秒 | 「見てみます」の下に波線 |
| 11.95秒 | キオスク画面の「9,00 SEK」を丸で囲む |
| 20.2秒 | 「押すだけ」からボタンへ矢印 |
| 31.95秒 | 「うわっ！」で頭の両側に3本線 |

### 全画面インサート（4か所）
| 時間 | 文字 | 背景 | 動き |
|---|---|---|---|
| 7.2秒 | いくら？ | 黄色 | 1文字ずつ落ちてくる |
| 13.7秒 | 安いんじゃ／ない？ | 黒 | 2行が左右から滑り込む |
| 26.0秒 | 食べます | 黄色 | ぼやけた巨大な文字から寄ってくる |
| 39.7秒 | リーズナブル | 黒 | 1文字ずつポンと膨らむ |

### AE上の構成
- 単語1つ＝「ヌル1つ＋テキストレイヤー」です（縦書きは1文字ずつのレイヤー）。ヌルの名前は `TELOP 開始秒 単語` です。
- 1文字ずつタイプする動きは、`Type` アニメーター（スケール・不透明度）と、単位を「インデックス」にした範囲セレクターの「開始」のキーフレームで作っています。
- 蛍光ペンは `highlighter` という名前のシェイプレイヤー（文字の下）で、横方向の拡大で伸ばしています。
- 手描き風の飾りは `DOODLE` という名前のシェイプレイヤーで、パスのトリミングの「終了」を0→100%に動かしています。
- 数字が回る動きは、ソーステキストのキーフレーム（停止）です。
- 単語の位置を変えたいときは、ヌルを動かしてください。

|---|---|---|

## 安全圏

Metaのリール向けガイドに合わせて、テロップはすべて次の範囲に収めています。

- 上 250px
- 下 670px
- 左 60px
- 右 120px
