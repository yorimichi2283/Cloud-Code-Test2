# IKEAソフトクリーム リール — After Effects 一式（フルテロップ・1文字ずつ版）

## 中身

| ファイル | 内容 |
|---|---|
| `build_ikea_edit.jsx` | AEで実行すると、コンポジションを丸ごと組み立てるスクリプト |
| `fonts/` | 使用フォント（M PLUS Rounded 1c Black） |
| `matte/person_matte.mp4` | 人物の切り抜きマスク（白＝人物）。「5倍濃縮」を頭の後ろに回すのに使用 |
| `sfx/sfx_mix.wav` | 効果音をタイミングどおりに並べた1本のトラック（控えめな音量） |
| `sfx/*.wav` | 効果音の単体ファイル（pop・whoosh・thump） |
| `preview.mp4` | 仕上がりイメージ（低画質の確認用） |

## 使い方

1. `fonts/` の `.ttf` をインストールし、AEを再起動する
2. AEで **ファイル → スクリプト → スクリプトファイルを実行…** を選び、`build_ikea_edit.jsx` を開く
   - フォルダの構成は変えずに、このフォルダの中から実行してください
3. ファイル選択の画面で、**編集前の高画質の素材動画**を選ぶ
4. `IKEA_SoftCream_Reel`（1080×1920・30fps）が自動で作られます

## テロップ

- しゃべりをすべて文字にしたフルテロップです。**1文字ずつ、その文字を話した瞬間に出ます**（音声認識で取った1文字ごとのタイミングを使っています）。
- 出方は場面ごとに変えています。
  | 種類 | 出方 | 主に使っている場面 |
  |---|---|---|
  | rise | 下から浮き上がる | 基本の話し言葉 |
  | pop | ゼロからポンと膨らむ | テンポの速い場面（キオスク、レジ前） |
  | drop | 上から落ちてくる | 冒頭、マシン、「食べます」「5倍濃縮」 |
  | blur | ぼかしから現れる | 「実際」「自動で」「口の中に入れた」 |
  | spin | くるっと回って入る | 「意外とね」 |
  | slam | 大きい状態から叩きつけて、少し揺れる | 金額や「押すだけ」などの強調 |
  | slide | 横から滑り込む（モーションブラー付き） | 「150円」 |
  | wave | 出たあとも文字が揺れ続ける | 「安い」「うわっ！」 |
- 表示中は全テロップが100→103.5%にゆっくり寄っていき、最後の0.1秒でフェードアウトします。
- 白の基本字幕は84pxで、下側に固定です。強調は黄色（#FFD21F）、120〜230pxです。
- 縁取りは細め（文字サイズの約2%）にし、うっすら影をつけて読みやすさを保っています。

### AE上の構成

- 1つのテロップは「ヌル1つ＋色ごとのテキストレイヤー」で組んであります。
  - ヌル（名前は `TELOP 開始秒 テキスト`）：寄り、叩きつけ、揺れ、スライドを担当
  - テキストレイヤー：`Reveal (speech timed)` アニメーターで、文字を1つずつ出します。範囲セレクターの単位は「インデックス」で、「開始」のキーフレームが話すタイミングに打ってあります。
  - 揺れ続ける文字（wave）には、ウィグリーセレクターを使っています。
- 文字を打ち替えた場合は、「開始」のキーフレームの位置で出るタイミングを調整してください。

## 安全圏

Metaのリール向けガイドに合わせて、テロップはすべて次の範囲に収めています。

- 下 670px
- 左 60px
- 右 120px
