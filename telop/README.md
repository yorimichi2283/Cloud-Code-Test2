# テロップ「激ヤバドリンクを / 飲んでみる」

バラエティ番組風（レンガ色の文字＋細い白フチ＋黒フチ＋ふわっと黒い影。色は参考画像から計測）のテロップアニメーションを、
After Effects 上で編集できる形で生成するスクリプトです。

![preview](preview/preview.gif)

| ファイル | 内容 |
| --- | --- |
| `telop_gekiyaba_drink.jsx` | AE で実行するとコンポ一式を作るスクリプト |
| `preview/preview.mp4` / `preview.gif` | 動きの確認用プレビュー（フォントは Noto Serif JP Black） |
| `preview/render_preview.py` | プレビューを書き出す Python スクリプト |

## 使い方

1. AE を開き **ファイル > スクリプト > スクリプトファイルを実行...** で `telop_gekiyaba_drink.jsx` を選ぶ
2. プロジェクトに `TELOP_激ヤバドリンク` フォルダができ、メインコンポが開く

### できるもの

```
TELOP_激ヤバドリンク (1920x1080 / 30fps / 4秒)
 ├ L2_飲んでみる        … 6フレーム遅れて登場
 └ L1_激ヤバドリンクを
     (各プリコンポの中身)
     ├ TEXT_文字を編集  … ここを打ち替えるとフチも追従
     ├ FILL_グラデ      … 文字色（エフェクト「グラデーション」、ほぼ単色）。TEXT_ のアルファでマット
     ├ STROKE_白フチ
     └ STROKE_外フチ
```

- **動き**: 120% → 100% に 5 フレームでスッと収まる＋4 フレームでフェードイン。最後は 5 フレームでフェードアウト
  （揺れは既定でオフ。欲しいときは `CONFIG.shake.amount` を 6〜10 程度に）
- **影**: メインコンポ側の各行レイヤーにドロップシャドウ
- モーションブラー ON

## 編集のコツ

- **文字を変える**: プリコンポ内 `TEXT_文字を編集` を打ち替えるだけ（白フチ・外フチはエクスプレッションで追従）
- **フォント・サイズを変える**: `TEXT_文字を編集` だけ変えれば OK。白フチ・外フチがフォント／サイズ／字間／太字ごと自動で追従し、
  フチの太さも「文字サイズ × %」なので、どのフォント・サイズでも同じバランスになる
- **フチの太さ・色**: `STROKE_白フチ` / `STROKE_外フチ` のエフェクト「フチの太さ(文字サイズ比%)」「フチの色」で調整
- **フチの角が尖る場合**: `STROKE_` の 2 レイヤーで文字パネルの「線の結合」を **ラウンド** に（古い AE はスクリプトから設定できないため）
- **文字色**: `FILL_グラデ` の「グラデーション」エフェクトで開始色/終了色を変更（文字の上端〜下端に自動で合う）
- **揺れ**: `CONFIG.shake.amount` を 0 より大きくして再実行すると、着地時に位置が揺れるエクスプレッションが付く
- **タイミング**: 行レイヤーごとドラッグすればキーも一緒に動く。まとめて作り直したいときは
  スクリプト冒頭の `CONFIG`（フォント候補、色、線幅、位置、登場/退場フレーム、拡大率）を書き換えて再実行

## フォント

**どのフォントでも使えます。** 作成後に `TEXT_文字を編集` のフォントを好きなものに変えるだけで、
フチ・文字色のグラデ・中心位置（拡大の基準点）がすべて新しいフォントの形と大きさに合わせて自動調整されます。

> フチの完全追従は AE 2020 (17.0) 以降のテキストスタイル式を使っています。
> それより古い AE では文字だけが追従するので、フォントは `TEXT_` と `STROKE_` の 3 レイヤーを同時選択して変えてください。

作成時の初期フォントは `CONFIG.fonts` の上から順に、インストール済みのものを使います（見つからなければ AE の既定フォント）。

1. Noto Serif JP Black（Google Fonts で無料。プレビューと同じ見た目）
2. 源ノ明朝 Heavy
3. ヒラギノ明朝 W6 / 游明朝 Demibold
4. ヒラギノ角ゴ W9 / 游ゴシック Bold

参考画像に近い極太系（例: Noto Serif JP Black、源ノ明朝 Heavy）がおすすめです。
毎回同じフォントで作りたい場合は、その PostScript 名を `fonts` の先頭に追加してください。

> スクリプトは UTF-8 (BOM 付き) で保存しています。エディタで編集した際は BOM 付きのまま保存してください（文字化け防止）。
