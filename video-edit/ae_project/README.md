# IKEAソフトクリーム リール — After Effects 一式（フルテロップ版）

## 中身

| ファイル | 内容 |
|---|---|
| `build_ikea_edit.jsx` | AEで実行すると、コンポジションを丸ごと組み立てるスクリプト |
| `fonts/` | 使用フォント（M PLUS Rounded 1c Black ／ しっぽり明朝 B1 ExtraBold） |
| `matte/person_matte.mp4` | 人物の切り抜きマスク（白＝人物）。「5倍濃縮」を頭の後ろに回すのに使用 |
| `sfx/sfx_mix.wav` | 効果音をタイミングどおりに並べた1本のトラック（控えめな音量） |
| `sfx/*.wav` | 効果音の単体ファイル（whoosh・thump） |
| `preview.mp4` | 仕上がりイメージ（低画質の確認用） |

## 使い方

1. `fonts/` の2つの `.ttf` をインストールし、AEを再起動する
2. AEで **ファイル → スクリプト → スクリプトファイルを実行…** を選び、`build_ikea_edit.jsx` を開く
   - フォルダの構成は変えずに、このフォルダの中から実行してください
3. ファイル選択の画面で、**編集前の高画質の素材動画**を選ぶ
4. `IKEA_SoftCream_Reel`（1080×1920・30fps）が自動で作られます

## テロップ

### 方針
- 話した言葉はすべて字幕にしています（フルテロップ）。
- **普段の字幕は動かしません**。話し始めにパッと出て（2フレームのフェード）、そのまま止まっています。白・84px・下側に固定です。
- 動きを入れるのは、**冒頭のフック**と**7か所の強調**だけです。

### 冒頭のフック（0〜2.1秒）
- 外観の映像で「IKEA」だとわかるので、店名の文字は入れていません。代わりに、話の中身から問いかけを作りました。
  - 「日本で50円の」（細い明朝・文字間が詰まりながら出る）
  - 「ソフトクリーム」（下の線から抜けてくる）
  - 「本場だと」（細い明朝・文字間が詰まりながら出る）
  - 「いくら？」（黄色・下から抜けてくる＋下線が伸びる）
- この間は、映像を40%暗くして文字を立たせています（`HOOK dim` レイヤー）。

### 強調（黄色・下から抜けてくる＋一部は下線が伸びる）
- 「1個50円」「150円」「1個112円」「食べます」「うわっ！」「5倍濃縮」（頭の後ろに回り込む）「リーズナブル」の7か所です。
- 7.2秒の黄色い全画面「いくら？」は、冒頭の問いかけを受け直す役割です。
- 強調しているテロップだけ、表示中に100→103%へゆっくり寄っていきます。

### AE上の構成
- 1つのテロップは「ヌル1つ＋色ごとのテキストレイヤー」で組んであります。
  - ヌル（名前は `TELOP 開始秒 テキスト`）：位置と、ゆっくり寄る動きを担当
  - テキストレイヤー：文字そのもの
- 下から抜けてくる動きは、テキストレイヤーのマスクと、`Rise` アニメーター（位置）で作っています。
- 文字間が詰まる動きは、`Track in` アニメーター（トラッキングと不透明度）で作っています。
- 下線は `underline` という名前のシェイプレイヤーで、横方向の拡大で伸ばしています。
- 文字を打ち替えたら、文字の長さに合わせてマスクと下線の幅を調整してください。

### 聞き取りに自信がない部分（確認してください）

| 時間 | 今の字幕 | 音声認識の結果 |
|---|---|---|
| 0.2秒 | スウェーデンのイケアを | 強い年のイケアを |
| 8.0秒 | 見てみます | 済みてみます |
| 32.8秒 | 色々うまい | 広く、うまい ／ 色々 |
| 39.7秒 | リーズナブルなので | リズムで なので |

## 安全圏

Metaのリール向けガイドに合わせて、テロップはすべて次の範囲に収めています。

- 上 250px
- 下 670px
- 左 60px
- 右 120px

赤い `GUIDE` レイヤーがその目安です。ガイドレイヤーなので書き出しには映りません。
