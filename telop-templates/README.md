# テロップテンプレート（Premiere Pro 用 .mogrt）

After Effects でスクリプトを1回実行すると、Premiere Pro で文字・色・サイズを変えられる
モーショングラフィックステンプレート（.mogrt）が2つできます。

| テンプレート | 中身 |
| --- | --- |
| **ルールテロップ** | 金枠＋ミント地＋集中線の帯。左上に1文字1マスのラベル（例：ルール）。本文は白文字＋黒の押し出し影で、`＊` で挟んだ部分だけ赤 |
| **セリフテロップ** | 白文字＋黒フチ＋ぼかし影 |

寸法と色は、もらったスクリーンショットを 1920×1080 に換算して測ったものです。
動き（IN アニメーション）は参考映像がまだ無いので仮のものです。

## 見た目の確認

`preview/index.html` をブラウザで開くと、スクリプトと同じ寸法・色・動きの式で描いたプレビューが見られます。
本文・ラベル・セリフを書き換えたり、アニメーションをスロー再生したりできます。

## 使い方

### 1. フォントを入れる（After Effects と Premiere を使う PC の両方）

.mogrt にはフォントが入らないので、使う PC すべてにインストールしてください。どれも無料です。

| 用途 | フォント | 入れるファイル |
| --- | --- | --- |
| ルールテロップの本文 | [Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP) | `static/NotoSansJP-Black.ttf` |
| ラベル（ルール） | [M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c) | `MPLUSRounded1c-Medium.ttf` |
| セリフ | [Kaisei Tokumin](https://fonts.google.com/specimen/Kaisei+Tokumin) | `KaiseiTokumin-ExtraBold.ttf` |

番組と同じ系統の有料フォント（モリサワなど）を持っている場合は、`TelopTemplates.jsx` の先頭近くにある
`fonts:` の3行を、そのフォントの PostScript 名に書き換えてから実行してください。

### 2. After Effects でスクリプトを実行（After Effects 2020 以降）

1. After Effects を開く（新規プロジェクトで OK）
2. **ファイル → スクリプト → スクリプトファイルを実行...** で `TelopTemplates.jsx` を選ぶ
3. 保存先フォルダーを聞かれるので選ぶ
   - キャンセルすると Premiere の「ローカルテンプレートフォルダー」に直接入り、Premiere 側で最初から一覧に出ます
4. 完了メッセージに、書き出した .mogrt の場所が出ます。フォントが足りない場合もここに出ます

作られたコンポジション（`TELOP_TEMPLATES` フォルダー）は After Effects 上でそのまま直せます。
直したあとは、エッセンシャルグラフィックスパネルの「モーショングラフィックステンプレートを書き出し」で書き出し直してください。

### 3. Premiere Pro で使う

1. .mogrt をタイムラインにドラッグ＆ドロップする
   （またはエッセンシャルグラフィックス／グラフィックテンプレートパネルからインストール）
2. クリップを選ぶと、エッセンシャルグラフィックス（新しい版ではプロパティパネル）に下の項目が出ます
3. 位置や全体の大きさは、Premiere の「モーション」（位置・スケール）で自由に動かせます
4. クリップの長さを伸ばしても、最初と最後のアニメーション部分は伸びません（保護領域を設定済み）

#### ルールテロップで変えられる項目

| 項目 | 説明 |
| --- | --- |
| 本文（＊で挟んだ部分が強調色） | `レシートに書かれているモノは＊現物と交換可能＊` のように、赤くしたい部分を `＊`（全角）か `*`（半角）で挟む。3か所まで |
| ラベル | 1文字ずつマスに入る。8文字まで。空にするとマスも消える |
| ラベルを表示 | チェックを外すとラベルを隠す |
| 本文の色／強調の色／影の色 | |
| 影の距離 (px) | 押し出し影の長さ。標準 11 |
| 文字サイズ (%) | 標準 100。長い本文は帯からはみ出さないよう自動で縮む |
| ラベル文字の色／帯の地の色／集中線の色／金枠の色（明・暗） | |
| 帯の幅 (%) | 標準 100（画面幅いっぱい）。ラベルも左端についていく |
| IN アニメーション／OUT アニメーション | 出る動き・消える動きの ON/OFF。OUT は標準で OFF |
| アニメーションの長さ (フレーム) | 標準 9。大きくするとゆっくりになる |

#### セリフテロップで変えられる項目

セリフ（改行すると上に積み上がる）、文字の色、フチの色、フチの太さ、影の色、影のぼかし、影の濃さ (%)、文字サイズ (%)、IN／OUT アニメーション、アニメーションの長さ (フレーム)。

## 制限

- ルールテロップの本文は1行用です（長いと自動で縮みます）
- 動きは仮のものです。参考映像の画面録画があれば、何フレームでどう動くかを測って合わせ込みます
- 効果音は .mogrt に入らないので、Premiere 側で置いてください

## 開発メモ

- 読みやすい元のソースは `src/TelopTemplates.src.jsx` です。配布用の `TelopTemplates.jsx` は
  日本語版 Windows の After Effects で文字化けしないよう、全角文字を `\uXXXX` に置き換えた ASCII のみのファイルです
- ソースを直したら、配布用ファイルを作り直してテストしてください

```sh
python3 tools/build.py                                   # TelopTemplates.jsx を生成
python3 tools/build.py --check                           # 生成し忘れがないか
npx eslint -c tools/eslint.config.mjs TelopTemplates.jsx  # ExtendScript (ES3) で動かない書き方がないか
node tools/test_jsx.js                                   # After Effects の模型の上で実行して式の値まで確かめる
```

`tools/test_jsx.js` は After Effects の模型（mock）の上で実行するテストです。プロパティ名の打ち間違い、
レイヤーやエフェクトの参照切れ、エクスプレッションの計算は確かめられますが、
After Effects 本体での表示は確かめられません。実機で気づいた点があれば教えてください。
