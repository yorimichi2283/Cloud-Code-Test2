# Telop Shifter

Premiere Pro用のUXPパネルプラグインです。タイムライン上で選択したテロップ（テキスト/グラフィック/MOGRTクリップ）の
位置（X, Y座標）とスケールを、まとめてリアルタイムに調整できます。

## できること

- Premiereのタイムラインで（例えばV3トラック上だけ）複数のテロップクリップをドラッグ選択
- パネルの「タイムラインの選択クリップを読み込む」を押すと、選択中の全クリップの現在の位置・スケールを記録
- X座標・Y座標・スケールはそれぞれ「−」「＋」ボタン、または数値を直接入力して1px単位で細かく調整可能
  （「移動幅」を10や50に切り替えれば大きい単位でも動かせる）
- ボタンを押す/数値を変えるたびに、選択した全クリップにまとめて、その場でリアルタイムに反映
- 「リセット」で読み込んだ時点の位置に一括で戻せる
- 通常のテキストクリップの「モーション」エフェクトの位置/スケールと、MOGRT（Essential Graphics）側で
  公開されている位置/スケール系パラメータの両方に対応（パラメータ名に "Position/位置" "Scale/スケール" を
  含むものを自動検出）

## 制限事項

- すでにキーフレームが打たれている位置/スケールパラメータは、意図しない上書きを避けるため対象外にしています
  （読み込み時のクリップ一覧に「キーフレーム済みのため対象外」と表示されます）
- パラメータの検出は表示名（英語 "Position"/"Scale"、日本語 "位置"/"スケール"）に基づく簡易マッチングです。
  Premiereの表示言語によっては見つからない場合があります
- ボタンのクリックや数値変更のたびにPremiereへの書き込みが発生するため、Undo履歴が複数回に分かれます。
  一連の調整全体を取り消したい場合は「リセット」ボタンの利用を推奨します

## セットアップ（UXP Developer Toolでの読み込み）

1. Premiere Pro 25.2以降がインストールされていること
2. [UXP Developer Tool](https://developer.adobe.com/creative-cloud/uxp/) をインストール
3. UXP Developer Toolで「Add Plugin」からこのリポジトリの `manifest.json` を選択して読み込み
4. Premiere Proでプロジェクトを開いた状態で、UXP Developer Tool上の「Load」を押す
5. Premiere Proのウィンドウメニューからパネル「Telop Shifter」を表示

## 使い方

1. Premiereのタイムラインで、調整したいテロップクリップをドラッグ（またはShift+クリック）で複数選択
2. パネルの「タイムラインの選択クリップを読み込む」ボタンを押す
3. 読み込んだクリップの一覧と、検出できた位置/スケールパラメータの数が表示される
4. 「移動幅」で1回のクリックあたりの移動量（1 / 10 / 50）を選ぶ
5. X座標・Y座標・スケールの「−」「＋」ボタンを押す（または数値欄に直接入力する）と、選択した全クリップの
   位置とサイズがまとめてリアルタイムに変わる。ボタンを押しっぱなしにすると連続で動く
6. 元に戻したい場合は「リセット」ボタンを押す

## ファイル構成

- `manifest.json` — UXPプラグインのマニフェスト
- `index.html` / `styles.css` — パネルのUI
- `index.js` — Premiere Pro UXP Scripting API (`require("premierepro")`) を使ったロジック本体
- `icons/` — パネル・プラグイン一覧用のアイコン（仮のプレースホルダー。差し替え可）

## 技術メモ

このプラグインは Adobe公式の `@adobe/premierepro` 型定義とサンプルリポジトリ
(`AdobeDocs/uxp-premiere-pro-samples`) のAPI仕様に基づいて実装しています。実機のPremiere Proでの
動作確認はこの開発環境では行えないため、UXP Developer Toolで読み込んでの実機テストをお願いします。
