# 「かながわの現場」オープニング＆テロップ（After Effects / Premiere Pro 用）

ドキュメンタリー「かながわの現場」用の **オープニング（約5秒）** と **テロップ3種** を、
After Effects のスクリプト1本で自動生成します。色・文字は Premiere Pro 上でも変更でき、
動きは After Effects のキーフレームで自由に調整できます。

| ファイル | 内容 |
|---|---|
| `KanagawaGenba_Builder.jsx` | **これを AE で実行**（ロゴ画像も中に入っているので、このファイル1つでOK） |
| `preview/preview_01_opening.mp4` | オープニングの簡易プレビュー |
| `preview/preview_02-04_telops.mp4` | テロップ3種の簡易プレビュー |
| `assets/` | 切り出したロゴ画像（1文字ずつの透過PNG）と元画像 |
| `src/`, `dev/` | 開発用（スクリプトの元ファイルと検証ツール。普段は触らなくてOK） |

> プレビュー動画は、スクリプトの動きを検証用に簡易描画したものです。フォント（実際はヒラギノ）やモーションブラーなど、細部は実際の AE の見た目と少し異なります。

## 作られるもの

### 01_OP_オープニング（5秒）
1. 0.0秒〜　水色の線が中央から引かれる
2. 0.3秒〜　線の下から「か・な・が・わ・の」が1文字ずつ跳ねて出てくる
3. 0.6秒〜　「現・場」が線の上から落ちてきて着地
4. 1.2〜3.4秒　ゆっくりズームで見せる
5. 3.35秒〜　ロゴが左上へ縮みながら移動し、白いプレートに収まる
6. 3.5秒〜　画面中央に線が走り、白い背景が **上下に割れて次のシーンが現れる**
7. 4.55秒〜　左上ロゴの状態で止まる（そのまま 02 の左上ロゴにつながる）

### 02_左上ロゴ＋上部タイトル
OP の最後と **まったく同じ位置・大きさ** の左上ロゴと、その右に伸びる黒帯のタイトル。
帯の長さは文字数に合わせて自動で伸び縮みします。

### 03_下部テロップ
画面下中央。帯が中央から左右に開き、下に水色の線が引かれます。

### 04_名前テロップ
画面左下。名前（黒帯）、肩書き（水色のタグ）、所属（白帯）が順に左から伸びて出ます。

## 使い方

### 1. After Effects でテンプレートを作る
1. After Effects を開く（新規プロジェクトがおすすめ）
2. **ファイル → スクリプト → スクリプトファイルを実行…** → `KanagawaGenba_Builder.jsx` を選ぶ
3. 完了メッセージのあと「MOGRT を書き出しますか？」と聞かれるので、Premiere で使うなら **OK** → 保存先フォルダを選ぶ
4. **プロジェクトを保存**（あとで動きを直すときに使います）

> ロゴ画像は実行時に「書類（Documents）/KanagawaGenba_Assets」に書き出されます。このフォルダは消さないでください。

### 2. Premiere Pro で使う（MOGRT）
1. Premiere の **エッセンシャルグラフィックス** パネル（または「グラフィックとタイトル」→「モーショングラフィックステンプレートをインストール」）で、書き出した `.mogrt` を読み込む
2. タイムラインの **映像の上のトラック（V2 など）** にドラッグ
3. クリップを選ぶと、文字・色・チェック項目を Premiere 上で直接変更できます

MOGRT の代わりに、保存した `.aep` を Premiere に読み込んで（Dynamic Link）使うこともできます。

### 3. OP から次のシーンへきれいにつなぐ配置
```
V3: [ 01_OP（5秒） ][ 02_左上ロゴ＋上部タイトル ……… ]
V1: [ 次のシーンの映像 ………………………………………………… ]
        ↑ 映像は OP の始まりから下に敷いておく
```
- OP の後半で背景が割れると、下に敷いた映像がそのまま見えてきます
- OP の直後に 02 を置けば、左上ロゴが途切れずに続きます（02 の「ロゴもアニメーションで出す」は **オフ** のまま）
- タイトルなしで左上ロゴだけ出したいときは、02 の「上部タイトルを表示」をオフにします
- 02 / 03 / 04 は長さを伸ばしても、出る動きと消える動きの速さは変わりません

## 色・文字の変え方

| コンポ | Premiere で変えられる項目 |
|---|---|
| 01 OP | 色：ひらがな／漢字／ライン／背景／左上プレート、「最後に左上ロゴを残す」 |
| 02 | 上部タイトル（文字）、上部タイトルを表示、ロゴもアニメーションで出す、最後にロゴも消す、各色 |
| 03 | 下部テロップ（文字）、帯／文字／アクセントの色 |
| 04 | 名前、肩書き、所属（文字）、各帯・文字の色 |

After Effects では、各コンポの一番上にある **「CTRL」レイヤーのエフェクト** で同じ項目を変更できます。

---

## 動きの変え方（After Effects）

- **タイミング・速さ**：各コンポの「CTRL」レイヤーにある `○○(%)` スライダー（例：`タイトル帯(%)`、`ロゴ移動(%)`）にキーフレームがあります。キーフレームを左右にずらすとタイミングが、間隔を詰めると速さが変わります。
- **OP の文字の跳ね方**：`_パーツ（触らなくてOK）` フォルダの `_ロゴ_hira`（かながわの）／`_ロゴ_kanji`（現場）コンポの中で、文字ごとの位置・回転のキーフレームを編集できます。
- **OP の背景の割れ方**：01 の「背景パネル（上）／（下）」レイヤーの位置キーフレーム。
- **左上ロゴの位置・大きさ**：01 の CTRL「左上ロゴの位置」「左上ロゴのサイズ(%)」。変えたときは、02 の「左上ロゴ（位置・大きさ）」レイヤーも同じ位置に合わせてください。

### 初期値をまとめて変えたいとき
`src/KanagawaGenba_Builder.src.jsx` の先頭にある「設定」（色・初期テキスト・フォント・タイミング）を書き換え、
`ae/dev` で `npm install && npm run build` を実行すると、新しい `KanagawaGenba_Builder.jsx` が作られます。

## 注意
- 対応バージョン：After Effects CC 2018（15.0）以降（2024 以降を推奨）
- フォントは **ヒラギノ角ゴシック** を使います（Mac 標準）。無い場合は Noto Sans JP / 游ゴシックなど、入っているフォントに自動で切り替わります。
- スクリプトのエクスプレッションはコンポ名を参照していないので、コンポ名を変えても動きます。

## 開発者向け（`dev/`）
After Effects なしで動作を確認するためのツールです。

- `npm run build` … `src/` から `KanagawaGenba_Builder.jsx` を生成（ロゴPNGを埋め込み、ES3構文をチェック）
- `npm test` … ビルド後、AE の DOM を模したモック上でスクリプトを実行。全エクスプレッションを複数の時刻で評価し、参照切れ・型の不一致・ロゴ画像の書き出しを検証
- `node render.js "<コンポ名の先頭>" <開始秒> <終了秒> <fps> <出力フォルダ> [背景.png]` … 簡易プレビュー画像を書き出し（Playwright / Chromium を使用）
- `python3 split_logo.py` … `assets/logo_source.jpg` から1文字ずつの透過PNGを作り直す
