# テロップ「激ヤバドリンクを / 飲んでみる」

バラエティ番組風（赤グラデ＋白フチ＋濃いフチ＋影）のテロップアニメーションを、
After Effects 上で編集できる形で生成するスクリプトです。

![preview](preview/preview.gif)

| ファイル | 内容 |
| --- | --- |
| `telop_gekiyaba_drink.jsx` | AE で実行するとコンポ一式を作るスクリプト |
| `preview/preview.mp4` / `preview.gif` | 動きの確認用プレビュー（フォントは Noto Serif JP Black） |
| `preview/render_preview.py` | プレビューを書き出す Python スクリプト |

## 使い方

1. AE を開き **ファイル > スクリプト > スクリプトファイルを実行...** で `telop_gekiyaba_drink.jsx` を選ぶ
2. プロジェクトに `TELOP_激ヤバドリンク` フォルダができ、メインコンポが開く

### できるもの

```
TELOP_激ヤバドリンク (1920x1080 / 30fps / 4秒)
 ├ L2_飲んでみる        … 9フレーム遅れて登場
 └ L1_激ヤバドリンクを
     (各プリコンポの中身)
     ├ TEXT_文字を編集  … ここを打ち替えるとフチも追従
     ├ FILL_グラデ      … 赤グラデ（エフェクト「グラデーション」）。TEXT_ のアルファでマット
     ├ STROKE_白フチ
     └ STROKE_外フチ
```

- **動き**: 380% から一気に縮んで着地 → 106% でちょい跳ね → 100%（回転 -10°→0°も同時）
  着地の瞬間に位置がブルッと揺れ、表示中はゆっくり 103% までズーム、最後は 6 フレームで縮んで消える
- **影**: メインコンポ側の各行レイヤーにドロップシャドウ
- モーションブラー ON

## 編集のコツ

- **文字を変える**: プリコンポ内 `TEXT_文字を編集` を打ち替えるだけ（白フチ・外フチはエクスプレッションで追従）
- **フォント・サイズを変える**: `TEXT_` `STROKE_白フチ` `STROKE_外フチ` の 3 レイヤーを選択して文字パネルで一括変更。
  大きさだけならメインコンポ側のスケールでも OK
- **フチの角が尖る場合**: 上の 3 レイヤーで文字パネルの「線の結合」を **ラウンド** に（古い AE はスクリプトから設定できないため）
- **色**: `FILL_グラデ` の「グラデーション」エフェクトで開始色/終了色を変更。フチ色は各 STROKE_ の文字色/線色
- **揺れ**: メインコンポの各行レイヤー「位置」のエクスプレッション冒頭の `startF` `lenF` `amp` を変更
- **タイミング**: 行レイヤーごとドラッグすればキーも一緒に動く。まとめて作り直したいときは
  スクリプト冒頭の `CONFIG`（フォント候補、色、線幅、位置、登場/退場フレーム）を書き換えて再実行

## フォント

`CONFIG.fonts` の上から順に、インストール済みのものを使います。

1. Noto Serif JP Black（Google Fonts で無料。プレビューと同じ見た目）
2. 源ノ明朝 Heavy
3. ヒラギノ明朝 W6 / 游明朝 Demibold
4. ヒラギノ角ゴ W9 / 游ゴシック Bold

参考画像に近い極太系（例: Noto Serif JP Black、源ノ明朝 Heavy）がおすすめです。
他のフォントを使う場合は PostScript 名を `fonts` の先頭に追加してください。

> スクリプトは UTF-8 (BOM 付き) で保存しています。エディタで編集した際は BOM 付きのまま保存してください（文字化け防止）。
