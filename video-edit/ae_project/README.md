# IKEAソフトクリーム リール — After Effects 一式（フルテロップ版）

## 中身

| ファイル | 内容 |
|---|---|
| `build_ikea_edit.jsx` | AEで実行すると、コンポジションを丸ごと組み立てるスクリプト |
| `fonts/` | 代わりのフォント（Zen Kaku Gothic Antique Black）。凸版文久見出しゴシックが無いときに使用 |
| `matte/person_matte.mp4` | 人物の切り抜きマスク（白＝人物）。「5倍濃縮」を頭の後ろに回すのに使用 |
| `sfx/sfx_mix.wav` | 効果音をタイミングどおりに並べた1本のトラック（控えめな音量） |
| `sfx/*.wav` | 効果音の単体ファイル（whoosh・thump） |
| `preview.mp4` | 仕上がりイメージ（低画質の確認用） |

## 使い方

1. Adobe Fonts で **凸版文久見出しゴシック** を有効にする（スクリプトが自動で使います）。
   使えない場合に備えて、`fonts/` の `.ttf` もインストールしておき、AEを再起動する
2. AEで **ファイル → スクリプト → スクリプトファイルを実行…** を選び、`build_ikea_edit.jsx` を開く
   - フォルダの構成は変えずに、このフォルダの中から実行してください
3. ファイル選択の画面で、**編集前の高画質の素材動画**を選ぶ
4. `IKEA_SoftCream_Reel`（1080×1920・30fps）が自動で作られます

## テロップ

### 方針
- 話した言葉はすべて字幕にしています（フルテロップ）。
- **画面に出るテロップは、同時に最大2行まで**です（生成時に自動でチェックしています）。
- 文字はすべて、画面の左右中央に揃えています。
- フォントは **凸版文久見出しゴシック**（Adobe Fonts）です。見つからない場合は、Zen Kaku Gothic Antique Black に自動で切り替わり、完了画面でお知らせします。プレビュー動画は Zen Kaku Gothic Antique で作っています。
- **普段の字幕は動かしません**。話し始めにパッと出て、そのまま止まっています。白・84px（長い行は自動で縮小）・下側に固定です。

### 冒頭のフック（0〜2.1秒）
- 「日本は**50円**」：下の線から抜けてきて、「50円」はスロットのように数字が回ってから止まります。
- 「本場は**いくら？**」：1文字ずつ上から落ちてきて、黄色の下線が伸びます。
- この間は、映像を55%暗くして文字を立たせています（`HOOK dim` レイヤー）。

### 全画面インサート（要所の4か所・それぞれ違う動き）
| 時間 | 文字 | 背景 | 動き |
|---|---|---|---|
| 7.2秒 | いくら？ | 黄色 | 1文字ずつ落ちてくる |
| 13.7秒 | 安いんじゃ／ない？ | 黒 | 2行が左右から滑り込む（モーションブラー付き） |
| 26.0秒 | 食べます | 黄色 | ぼやけた巨大な文字から、ドンと寄ってくる |
| 39.7秒 | リーズナブル | 黒 | 1文字ずつポンと膨らむ |

文字は画面のど真ん中（540, 960）に置いています。

### 強調（それぞれ違う動き）
| 時間 | 文字 | 動き |
|---|---|---|
| 3.7秒 | 1個**50円** | ポンと弾む＋数字が回って止まる |
| 11.7秒 | **150円** | 右から滑り込む＋数字が回って止まる＋下線 |
| 15.5秒 | 1個**112円** | 下の線から抜けてくる＋数字が回って止まる＋下線 |
| 20.1秒 | **押すだけ**ですね | ボタンのようにグニッと潰れて戻る |
| 31.9秒 | **うわっ！**って | 大きく出てから縮み、ブルブル揺れる |
| 36.2秒 | **5倍濃縮** | 1文字ずつ落ちてきて、頭の後ろに回り込む |

- それ以外の字幕は動かしません（読みやすさを優先）。
- 動きのあるテロップは、表示中に100→103%へゆっくり寄っていきます。
- 数字が回るときは、ごく小さなカチカチ音が入ります。

### AE上の構成
- 1つのテロップは「ヌル1つ＋色ごとのテキストレイヤー」で組んであります。
  - ヌル（名前は `TELOP 開始秒 テキスト`）：位置と、ゆっくり寄る動きを担当
  - テキストレイヤー：文字そのもの
- 下から抜けてくる動きは、テキストレイヤーのマスクと、`Rise` アニメーター（位置）で作っています。
- 1文字ずつの動き（`Cascade` ／ `Pop chars`）は、範囲セレクターのオフセットを -100→100 に動かして作っています。
- 左右から滑り込む動き（`Swipe`）は、行ごとのテキストアニメーター（位置）で作っています。
- 数字が回る動きは、ソーステキストのキーフレーム（停止）で作っています。数字を変えたい場合は、最後のキーフレームの文字を直してください。
- 「食べます」のぼかしは、ブラー（ガウス）エフェクトのキーフレームで作っています。
- 下線は `underline` という名前のシェイプレイヤーで、横方向の拡大で伸ばしています。
- 文字を打ち替えたら、文字の長さに合わせてマスクと下線の幅を調整してください。

## 安全圏

Metaのリール向けガイドに合わせて、テロップはすべて次の範囲に収めています。

- 上 250px
- 下 670px
- 左 60px
- 右 120px

赤い `GUIDE` レイヤーがその目安です。ガイドレイヤーなので書き出しには映りません。
