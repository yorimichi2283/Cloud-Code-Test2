説テロップ工房

極太の明朝体に黒い縁、ぼかした影、そしてストロボで点滅しながら出る。そんなバラエティ番組風のテロップを、文字を打つだけで再生できます。

PGM 00:00:00;00
TITLE SAFE 90%
種類

改行で行が分かれます。*文字* で強調色。「説の提示」では行末の「説」が大きくなります。

出し方
向き
書体
背景

Premiere Pro 用に書き出す

今の設定で、背景が透明な動画（ProRes 4444 の .mov）を作るコマンドです。最初の準備は README を見てください。

書き出した .mov を、映像より上のトラック（V2 など）に置くだけで重なります。
