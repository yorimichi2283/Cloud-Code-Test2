# IKEAソフトクリーム リール — After Effects 一式

## 中身

| ファイル | 内容 |
|---|---|
| `build_ikea_edit.jsx` | AEで実行すると、コンポジションを丸ごと組み立てるスクリプト |
| `fonts/` | 使用フォント2種（M PLUS Rounded 1c Black ／ しっぽり明朝 B1 ExtraBold） |
| `matte/person_matte.mp4` | 人物の切り抜きマスク（白＝人物）。文字を人の後ろに回り込ませる部分で使用 |
| `sfx/sfx_mix.wav` | 効果音をタイミングどおりに並べた1本のトラック |
| `sfx/*.wav` | 効果音の単体ファイル（whoosh・pop・thump・tick・swell） |
| `preview.mp4` | 仕上がりイメージ（低画質の確認用） |

## 使い方

1. `fonts/` の2つの `.ttf` をインストールし、AEを再起動する
2. AEで **ファイル → スクリプト → スクリプトファイルを実行…** を選び、`build_ikea_edit.jsx` を開く
   - フォルダの構成は変えずに、このフォルダの中から実行してください（マスクと効果音を相対パスで読み込みます）
3. ファイル選択の画面で、**編集前の高画質の素材動画**を選ぶ
4. `IKEA_SoftCream_Reel`（1080×1920・30fps・42.2秒）が自動で作られます

素材を後から差し替える場合は、プロジェクトパネルで素材を選んで **ファイル → フッテージの置き換え** を使ってください。全レイヤーが一度に入れ替わります。

## コンポジションの構成（下から順）

- `FOOTAGE (base)`：素材
- 人物の後ろに回る文字（`VANILJ`）
- `PERSON cut-out` ＋ `PERSON matte (luma)`：人物だけを切り抜いて文字の上に重ねたもの
- 手前の文字（レイヤー名は「開始秒 テキスト」）
- `CARD 1〜3`：全画面のインサート（レンガ色の画面と、四隅にカギカッコ枠のあるベージュの画面）
- `SFX mix`：効果音
- `GUIDE Reels safe zone`：赤い部分がリールのUIで隠れる範囲です。ガイドレイヤーなので書き出しには映りません

## 安全圏

Metaのリール向けガイドに合わせて、テロップはすべて次の範囲に収めています。

- 上 250px
- 下 670px
- 左 60px
- 右 120px（いいね・コメントなどのボタンがあるため広めに空けています）

文字を動かすときは、赤いガイドの内側に収めてください。

## アニメーションの作り

すべてキーフレームとテキストアニメーターで組んであり、エクスプレッションは使っていません。

| 種類 | 作り |
|---|---|
| 飛び込み | 位置のキーフレーム（Expo Out相当のイージング）＋レイヤーのモーションブラー |
| ぼかしイン | スケール 118→100%、ブラー（ガウス）60→0、不透明度 |
| ポップ | スケール 55→108→100% |
| タイピング | テキストアニメーター（不透明度0、範囲セレクターの開始 0→100%、滑らかさ 0%） |
| 1文字ずつ落下 | テキストアニメーター（位置・不透明度、シェイプ：上へ傾斜、イーズ（高）100%、オフセット -100→100%） |

文字の内容は、テキストを直接打ち替えればそのまま動きが引き継がれます。

## 補足

- 人物マスクは圧縮版の素材から作ったものです。高画質版の素材とカットや尺が同じであれば、そのまま合います。縁が気になる場合は、`PERSON cut-out` にロトブラシを使えばより精密になります。
