# 水ダウ風テロップ（Premiere Pro 用 .mogrt）

いただいた 4 本の画面収録から、テロップの配置・色・アニメーションのタイミングを測って再現した
モーショングラフィックステンプレートです。After Effects でスクリプトを 1 回実行すると
`.mogrt` が書き出され（効果音なし版と効果音入り版）、Premiere Pro のエッセンシャルグラフィックスパネルから
**文字・色・大きさ・書体・アニメーション**を自由に変更できます。

| # | テンプレート名 | 元の映像 | アニメーション |
|---|---|---|---|
| 1 | 水ダウ風_地名＋日数 | 「三重県木曽岬町」「7日目」 | 収録が一時停止中で登場の動きが映っていないため、既定はカット。横ブラー／フェードも選べます |
| 2 | 水ダウ風_黄色デカ文字ズーム | 「目標の100枚達成」 | 表示中ずっとゆっくり拡大（映像では約 1%/秒） |
| 3 | 水ダウ風_青グロー2段 | 「ベーゴマ職人の数は‥」「7人のみ」 | 2 段目が横ブラーで登場 → 少し遅れて灰色から白に光り、青いグローが広がる |
| 4 | 水ダウ風_ランキングボード | 「絶滅危惧アイテム⑤ そろばん」「7社」 | 下の黒箱が上から伸びて出現し、上の箱を押し上げる → 白いフラッシュが引いて黒になる |

> 元の映像は TVer の 2 倍速再生だったため、タイミングは通常速度（29.97fps）に換算しています。

## 必要なもの

- **After Effects 2020（17.0）以降**（テンプレートを書き出すために 1 回だけ使います。2024 以降を推奨）
- **Premiere Pro 2020 以降**

## 1. After Effects で .mogrt を書き出す

1. zip を解凍した `mizudau-telop` フォルダを、そのままの構成で置いておく
   （効果音はスクリプトと同じフォルダの `se/単体/` から読み込みます）
2. After Effects を開き、［ファイル］→［スクリプト］→［スクリプトファイルを実行...］で `MizudauTelop_MOGRT_Builder.jsx` を選ぶ
3. 確認ダイアログで［OK］→ 新しいプロジェクトに 4 つのコンポジションが作られます
4. 保存先フォルダを選ぶと、次のファイルが保存されます
   - `水ダウ風_地名＋日数.mogrt` など 4 つ（効果音なし）
   - `水ダウ風_地名＋日数（効果音あり）.mogrt` など 4 つ（効果音入り）
   - `水ダウ風テロップ.aep`（効果音入り。After Effects で細かく作り込みたいとき用）

効果音のフォルダが見つからないときは、フォルダを選ぶ画面が出ます。`se/単体` を選んでください
（キャンセルすると効果音なし版だけ書き出します）。

書き出しに失敗する場合は、After Effects の［設定］→［スクリプトとエクスプレッション］で
「スクリプトによるファイルへの書き込みとネットワークへのアクセスを許可」をオンにしてから、もう一度実行してください。

## 2. Premiere Pro で使う

1. `.mogrt` をタイムラインにドラッグ
   （またはエッセンシャルグラフィックスパネルの［参照］右下にある「モーショングラフィックステンプレートをインストール」から登録）
2. クリップを選び、エッセンシャルグラフィックスパネルの［編集］タブで各項目を変更
3. 画面全体での位置・大きさは、通常のクリップと同じく［エフェクトコントロール］の［モーション］でも動かせます

### 変更できる項目

**共通**
- テキスト … そのまま打ち替えられます（箱の大きさや下線の長さは文字に合わせて自動で伸び縮み）
- 大きさ … `50` が元の大きさ（100 で 2 倍、25 で半分）
- 書体 … インストールされている書体から選べます（下の「書体について」参照）
- 色 … 文字・フチ・影・グロー・箱など、パーツごとに変更できます
- アニメーションの時間 … フレーム単位（29.97fps。30 フレーム ≒ 1 秒）

**1. 地名＋日数**：登場アニメ（カット／横ブラーイン／フェードイン）、地名と日数それぞれの表示切替・位置・大きさ・書体・文字色・フチ・影、赤い下線の色と長さ、日数の横幅と箱の色・不透明度

**2. 黄色デカ文字ズーム**：登場アニメ、ゆっくりズーム量（クリップの最後で何 % 大きくなるか）、位置・大きさ・書体・文字色・フチ・影の色と濃さ

**3. 青グロー 2 段**：1 段目・2 段目それぞれの表示切替・位置・大きさ・書体・文字色・グロー色・グローの広さ。2 段目のアニメーション（オン／オフ、出るタイミング、横ブラーの長さと強さ、横スライド量、光り始めと光る長さ、光る前の明るさ）。1 段目も横ブラーで登場させるかどうか

**4. ランキングボード**：ボード全体の大きさ、ラベル・メイン・数字・単位の書体と色、箱・枠・枠線の色、下の箱の表示切替・色・不透明度。下の箱のアニメーション（オン／オフ、出るタイミング、伸びる長さ、押し上げ量、白フラッシュの長さと強さ）

### クリップの長さを変えたとき

- 冒頭（1・2 は 1 秒、3・4 は 2.5 秒）は保護領域にしてあるので、クリップを伸ばしても縮めても登場アニメの速さは変わりません。
- 「2. 黄色デカ文字ズーム」のズームはクリップ全体にかけて進みます（長いクリップほどゆっくり）。

## 効果音（se/）

テロップの動きに合わせた効果音です。すべてプログラムで一から合成したオリジナル音源なので、
YouTube などでも著作権を気にせず使えます（WAV / 48kHz / 16bit / ステレオ）。

> いただいた画面収録には番組の音声が入っていなかった（マウスのクリック音程度）ため、番組で使われている効果音そのものではなく、バラエティ番組でよく使われるタイプの音を作っています。

### 「（効果音あり）」の .mogrt（いちばん簡単）

タイムラインに置くだけで、テロップの動きに合わせて効果音が鳴ります。

| テンプレート | 鳴る音とタイミング |
|---|---|
| 地名＋日数 | 0 フレーム目に「ピコン」 |
| 黄色デカ文字ズーム | 0 フレーム目に「ドーン」 |
| 青グロー2段 | 30 フレーム目に「シュッ」（2 段目の横ブラー）、41 フレーム目に「キラーン」（光る瞬間） |
| ランキングボード | 30 フレーム目に「ドン」（下の箱が出る瞬間） |

**注意:** .mogrt に入れた音は書き出した時点のまま固定されます。Premiere で
「2段目が出るタイミング」「光り始め」「下の箱が出るタイミング」などを変えても、音は元の位置で鳴ります。
音量を変えたい・別の音にしたい・タイミングを変えたい場合は、**効果音なしの .mogrt ＋ 下の WAV** を使ってください。

### WAV（自由に置く場合）

`se/テンプレ同期/` の WAV は、上の表と同じタイミングで鳴るように作ってあります。
効果音なしの .mogrt と同じ開始位置に置き、2 つのクリップを選んで右クリック →［リンク］すると一緒に動かせます。

`se/単体/` は 1 音ずつのファイルです（先頭の SE01〜SE07 はスクリプトが音を探す目印なので、名前は変えないでください）。

| ファイル | 向いている場面 |
|---|---|
| SE01_シュッ_横ブラー.wav | 横ブラーで文字が飛び込むとき |
| SE02_キラーン_光る.wav | 文字が光る・グローが広がるとき |
| SE03_ドン_箱が出る.wav | 箱やテロップがドンと出るとき |
| SE04_ドーン_デカ文字.wav | 大きな文字がドーンと出るとき（重めの余韻） |
| SE05_ジャン_決め.wav | オチ・決めの一言 |
| SE06_ピコン_テロップ.wav | 地名・説明テロップなど軽く出すとき |
| SE07_シャキーン.wav | テロップがシャキーンと光るとき |

音色を変えたいときは `se/make_se.py` の数値を変えて `python3 se/make_se.py` を実行すると作り直せます。
After Effects 側で別の音にしたい場合は、`se/単体/` の同じ番号のファイルを差し替えてからスクリプトを実行し直してください。

## 書体について

番組のテロップは市販のフォント（モリサワなど）が使われているため、同じ書体がないと形は完全には一致しません。
スクリプト実行時にインストールされている書体を調べ、近いものを自動で選びます。

| 用途 | 優先順（見つかったものを使用） |
|---|---|
| 太い明朝（地名・黄色デカ文字・7人のみ） | 見出ミンMA31 → 小塚明朝 H → ヒラギノ明朝 W6 → 游明朝 |
| 細い明朝（ベーゴマ職人の数は‥） | ヒラギノ明朝 W3 → 小塚明朝 R → 游明朝 |
| 太いゴシック（7日目・ボード） | 見出ゴMB31 → ヒラギノ角ゴ W9 → 小塚ゴシック H → 游ゴシック |

**見出ミンMA31・見出ゴMB31 は Adobe Fonts で無料でアクティベートできます。** これらを入れてからスクリプトを実行すると、番組の雰囲気にかなり近づきます。
書体を追加したあとは、スクリプトをもう一度実行すると書体メニューに反映されます。

## 再現していない部分

- ランキングボードのバラとツタの飾り（番組オリジナルのイラストのため）。必要なら画像を上に重ねてください。
- 背景の水色の和柄（テロップではなく背景素材のため）。

## 開発用（dev/）

After Effects を使わずにスクリプトを検証するためのツールです。

```sh
node dev/aemock.js           # AE のモック上でスクリプトを実行（書き出しまで）
node dev/evalexpr.js         # 生成された全エクスプレッションを 0〜3 秒の各フレームで評価
node dev/evalexpr.js --set=IN_Type=2,L2_Anim=0   # コントロールの値を変えて評価
node dev/evalexpr.js --dump=geo.json && python3 dev/render_preview.py geo.json out/   # 配置確認用の簡易プレビュー
```
